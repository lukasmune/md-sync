# gifa-sync
[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

Python-based synchronization prototype that retrieves exhibitor information directly from GIFA's directory API, filters the source data into usable exhibitor profiles, resolves company identity across records, and stores the result in a persistent SQLite database.
